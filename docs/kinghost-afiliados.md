## Uso no projeto

A página `/melhores-hospedagens` usa o campo `affiliate` de `src/HostingProviders.php` para os links comerciais dos cards, da tabela e do acesso ao site oficial. KingHost usa o destino Hospedagem de Sites; KingHost VPS usa Servidor VPS. O template aplica `rel="sponsored nofollow noopener"` aos links de afiliados.

Os campos `official` e `evidence` preservam os endereços de referência editorial. Os demais links acima ficam disponíveis para futuros conteúdos, conforme o serviço mencionado.
